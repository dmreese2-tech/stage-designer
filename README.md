# 🎭 Stage Designer
**Stage set & lighting layout tool for Burgdorff Center for the Performing Arts**

Live at: `https://apps.upstage.systems/` (GitHub Pages deploy from `main`)

## Features
- Plan view: venue/stage outline, set pieces, battens, lighting, layers, comment pins, PDF plots
- 3D view: set and lighting, beam cones, audience sightlines, walk mode, glTF / USDZ (AR) / MVR export
- Paperwork: patch, load, colour cuts, equipment key, focus chart, side section, CSV
- Build: templates for flats, platforms, stairs, triangles, curved flats, columns, arches, soft goods; cut lists, sheet layouts, assembly steps, DXF, build status, Shop Standards
- Share links, revision compare, venue library

See `CHANGES.md` for the round-by-round change log.

## Develop
```
npm install
npm run dev      # local dev server
npm test         # construction engine tests
npm run build
```
